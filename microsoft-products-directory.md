# Microsoft Products Directory
### Beginner-friendly guide to the products shown in the Microsoft Product Directory screenshots

This guide explains the Microsoft products, services, programming languages, platforms, and tools visible in the supplied screenshots. It is written as a learning reference for students, developers, IT professionals, and business users.

> **Note:** The directory includes different kinds of technology. For example, C# and Java are programming languages; Azure is a cloud platform; Microsoft 365 is a productivity suite; and OpenAPI is a specification used to describe APIs.

## Development languages and frameworks

### .NET
**What it is:** A free, open-source development platform from Microsoft for building applications. It includes runtime components, libraries, language support, and development tools.

**What it is used for:** Web APIs, websites, desktop applications, cloud services, mobile apps, games, and background services. Developers commonly use C#, F#, or Visual Basic with .NET.

**Example:** Build a C# web API that stores student records in a database and serves data to a website or mobile app.

### .NET MAUI
**What it is:** .NET Multi-platform App UI, a framework for building native apps for Android, iOS, macOS, and Windows from a shared .NET codebase.

**What it is used for:** Cross-platform mobile and desktop applications where a team wants to share business logic and much of the user interface code.

**Example:** Create a campus attendance app that runs on Android, iPhone, and Windows.

### Adaptive Cards
**What it is:** A platform-independent JSON format for presenting compact, interactive content in supported apps and services.

**What it is used for:** Showing information and simple actions inside chat tools, bots, notifications, and workflow messages without building a completely separate interface for each host app.

**Example:** A Teams bot sends an approval card with request details and Approve/Reject buttons.

### ASP.NET Core
**What it is:** A modern, open-source, cross-platform framework in .NET for building web applications and HTTP APIs.

**What it is used for:** Websites, REST APIs, real-time services, backend systems, and cloud-hosted applications.

**Example:** Build a backend API for a library management system, with endpoints for books, members, and borrowing records.

### C++
**What it is:** A general-purpose programming language that provides low-level memory control alongside high-level programming features.

**What it is used for:** Operating systems, game engines, embedded software, performance-intensive applications, browsers, and systems programming.

**Example:** Develop a fast simulation or a component of a game engine where performance and hardware control matter.

### C#
**What it is:** A modern, strongly typed programming language developed by Microsoft and commonly used with .NET.

**What it is used for:** Web backends, desktop applications, cloud services, business software, games with Unity, and automation tools.

**Example:** Write a C# application that manages student details and saves them to a database.

### Java
**What it is:** A widely used, object-oriented programming language and runtime ecosystem designed for portability across supported platforms.

**What it is used for:** Enterprise applications, Android development, backend services, financial systems, and educational programming.

**Example:** Create a Java-based student result management system using classes, objects, and database connectivity.

## Cloud, data, and developer platforms

### Azure
**What it is:** Microsoft's cloud computing platform, offering computing, storage, networking, databases, analytics, AI, security, and application-hosting services.

**What it is used for:** Hosting websites and APIs, storing files, running virtual machines, deploying databases, building AI applications, backup, and disaster recovery.

**Example:** Deploy a Flask or ASP.NET application to Azure and use cloud storage for uploaded documents.

### Microsoft Fabric
**What it is:** An end-to-end analytics platform that brings together data engineering, data integration, data warehousing, data science, real-time analytics, and business intelligence experiences.

**What it is used for:** Collecting and preparing data, managing analytical data, running analysis, and creating reports within an integrated environment.

**Example:** Combine sales data from several systems and create a report showing monthly revenue trends.

### Microsoft Graph
**What it is:** A unified API endpoint for accessing data and services across Microsoft cloud products, subject to permissions and licensing.

**What it is used for:** Integrating applications with Microsoft 365 data such as users, groups, calendars, mail, files, and Teams resources.

**Example:** An approved campus application reads a user's calendar events after the user or administrator grants the required permissions.

### OData
**What it is:** Open Data Protocol, a standardized approach for building and consuming REST-style data APIs.

**What it is used for:** Querying and updating structured data using consistent URL conventions and query options.

**Example:** A client requests selected student records from a service using filters and selected fields, if the service supports OData.

### OpenAPI
**What it is:** A language-agnostic specification for describing HTTP APIs in a machine-readable document.

**What it is used for:** Documenting endpoints, request parameters, response formats, and authentication; generating interactive API documentation and client/server code.

**Example:** Describe a college management API in an OpenAPI file so developers can inspect and test its endpoints.

### Power Query M
**What it is:** The M formula language used by Power Query for data extraction, transformation, and loading (ETL).

**What it is used for:** Connecting to sources, cleaning data, changing data types, merging tables, filtering rows, and shaping datasets for reports.

**Example:** Import a spreadsheet of marks, remove blank rows, standardize column names, and combine it with student information.

### Semantic Kernel
**What it is:** An open-source SDK for integrating AI models with application code, tools, and business processes.

**What it is used for:** Building AI-assisted applications that combine model responses with functions, plugins, memory or retrieval components, and orchestration.

**Example:** Build a support assistant that can answer questions and call a permitted function to look up an order status.

### SQL Server
**What it is:** Microsoft's relational database management system for storing, querying, and managing structured data.

**What it is used for:** Transactional applications, reporting, business databases, data warehousing, and enterprise data management.

**Example:** Store customer, product, and order tables for an e-commerce application and query them using SQL.

### Visual Studio
**What it is:** Microsoft's integrated development environment (IDE) for writing, debugging, testing, and deploying software.

**What it is used for:** Developing .NET, C++, web, cloud, and other supported applications. It includes an editor, debugger, project tools, testing support, and extensions.

**Example:** Create a C# console application, set breakpoints, inspect variables, and debug errors.

### vcpkg
**What it is:** Microsoft's open-source C/C++ package manager.

**What it is used for:** Finding, installing, and managing C/C++ libraries and their dependencies across supported development environments.

**Example:** Add a third-party networking or image-processing library to a C++ project without manually managing every dependency.

## Dynamics 365 business applications

Dynamics 365 is a family of business applications for areas such as finance, sales, customer service, operations, commerce, and human resources. Organizations use individual applications or integrate several of them.

### Dynamics 365
**What it is:** The overall Microsoft family of business applications combining enterprise resource planning (ERP) and customer relationship management (CRM) capabilities.

**What it is used for:** Managing business processes such as customer relationships, finance, supply chains, projects, service operations, and sales.

**Example:** A company tracks leads in Sales, handles support cases in Customer Service, and manages financial transactions in Finance.

### Dynamics 365 Business Central
**What it is:** An ERP application aimed mainly at small and medium-sized organizations.

**What it is used for:** Connecting finance, sales, purchasing, inventory, projects, and operational processes.

**Example:** A small distributor manages purchase orders, stock levels, invoices, and financial reports in one system.

### Dynamics 365 Commerce
**What it is:** A commerce solution for managing retail and digital commerce operations.

**What it is used for:** Connecting store operations, online shopping, product catalogs, pricing, promotions, and customer experiences.

**Example:** A retailer manages product availability and promotions across physical stores and an online shop.

### Dynamics 365 Customer Insights
**What it is:** A customer data and journey solution that helps organizations unify customer information and use it for insights and engagement.

**What it is used for:** Combining customer data from supported sources, creating audience segments, understanding customer behavior, and orchestrating personalized journeys.

**Example:** A university groups prospective students by interests and sends relevant event information with appropriate consent and permissions.

### Dynamics 365 Customer Service
**What it is:** A customer support application for managing service requests and customer interactions.

**What it is used for:** Case management, service queues, knowledge articles, support workflows, and agent productivity.

**Example:** A support team records a customer's issue, assigns it to an agent, tracks its status, and documents the resolution.

### Dynamics 365 Field Service
**What it is:** A service-management application for organizations whose employees perform work at customer locations.

**What it is used for:** Scheduling technicians, managing work orders, tracking equipment, planning resources, and recording on-site service activity.

**Example:** A maintenance company schedules a technician to repair a machine at a customer's facility.

### Dynamics 365 Finance
**What it is:** An enterprise finance and operations application for financial management.

**What it is used for:** General ledger, accounts payable and receivable, budgeting, financial reporting, and related business controls.

**Example:** A company records invoices, tracks payments, and prepares financial statements.

### Dynamics 365 Guides
**What it is:** A mixed-reality assistance application designed to guide workers through procedures using digital instructions in supported devices and environments.

**What it is used for:** Training, guided work instructions, and step-by-step operational support.

**Example:** A technician follows visual instructions while learning how to inspect a piece of equipment.

### Dynamics 365 Human Resources
**What it is:** A human-resources management application within the Dynamics 365 ecosystem.

**What it is used for:** Supporting employee and HR processes such as personnel information, leave and absence, benefits, and workforce administration, depending on configuration and connected services.

**Example:** HR staff maintain employee records and manage leave-related processes.

### Dynamics 365 Project Operations
**What it is:** A business application for organizations that deliver project-based services.

**What it is used for:** Connecting project sales, staffing, project planning, time and expense tracking, delivery, and project financials.

**Example:** A consulting company plans project resources, records employee time, and tracks project profitability.

### Dynamics 365 Remote Assist
**What it is:** A remote collaboration solution designed to help field workers connect with remote experts, including through supported mixed-reality experiences.

**What it is used for:** Remote troubleshooting, expert guidance, and collaboration during maintenance or repair.

**Example:** A field technician shares a live view of equipment with an expert who provides guidance remotely.

### Dynamics 365 Sales
**What it is:** A sales-management application for tracking customer relationships and sales activities.

**What it is used for:** Managing leads, accounts, contacts, opportunities, sales pipelines, and follow-up activities.

**Example:** A sales representative records a prospective customer, schedules a meeting, and tracks the deal through its stages.

### Dynamics 365 Supply Chain Management
**What it is:** An enterprise application for planning and managing supply-chain and operational processes.

**What it is used for:** Procurement, inventory, manufacturing, warehousing, logistics, and demand planning.

**Example:** A manufacturer tracks raw materials, production orders, warehouse stock, and shipments.

## Microsoft 365, collaboration, and employee tools

### Microsoft 365
**What it is:** A subscription-based productivity and collaboration ecosystem that can include apps and services such as Word, Excel, PowerPoint, Outlook, Teams, OneDrive, and enterprise management capabilities, depending on the plan.

**What it is used for:** Creating documents, communicating, holding meetings, storing and sharing files, and collaborating.

**Example:** A student writes a report in Word, analyzes data in Excel, stores files in OneDrive, and collaborates through Teams.

### Microsoft Advertising
**What it is:** Microsoft's digital advertising platform for creating and managing ads across supported Microsoft search and audience properties.

**What it is used for:** Running search and other digital advertising campaigns, managing targeting, budgets, and campaign performance.

**Example:** A business creates a search advertising campaign and reviews impressions, clicks, and conversions.

### Microsoft Agent 365
**What it is:** Microsoft's agent-management and governance offering, announced as part of its evolving Microsoft 365 AI/agent ecosystem. Availability and capabilities may depend on Microsoft's current release and licensing.

**What it is intended for:** Helping organizations manage, govern, secure, and oversee AI agents used across their environment.

**Example:** An IT team establishes organizational controls and oversight for approved AI agents rather than allowing unmanaged agents to operate without governance.

### Microsoft Clipchamp
**What it is:** Microsoft's video-editing application.

**What it is used for:** Creating and editing videos with clips, text, transitions, audio, screen recordings, and templates.

**Example:** Create a short project demonstration video with a title, screen recording, narration, and captions.

### Microsoft Cloud
**What it is:** A broad term for Microsoft's cloud services and platforms, including Azure and cloud-based Microsoft business and productivity services.

**What it is used for:** Hosting applications, storing data, collaboration, identity, security, analytics, and business workloads delivered through cloud services.

**Example:** An organization uses cloud-hosted email, shared files, and a web application instead of operating every service on local servers.

### Microsoft Compliance
**What it is:** Microsoft's compliance capabilities and solutions for helping organizations meet regulatory, legal, and internal information-governance requirements.

**What it is used for:** Supporting data retention, records management, eDiscovery, auditing, information protection, and compliance workflows, depending on the product and license.

**Example:** A company applies retention rules to business records and searches relevant content during an authorized investigation.

### Microsoft Copilot
**What it is:** Microsoft's brand for AI-powered assistants and experiences across products. Exact features differ between consumer, Windows, Microsoft 365, and other Copilot offerings.

**What it is used for:** Assisting with tasks such as drafting, summarizing, asking questions, analyzing information, and generating content within supported products.

**Example:** A user asks a Copilot experience to summarize a document or help draft an email, subject to the product's capabilities and data permissions.

### Microsoft Copilot Studio
**What it is:** A low-code platform for creating, configuring, and publishing conversational agents and copilots.

**What it is used for:** Building agents that answer questions from approved knowledge sources, interact with users, and connect to workflows or business systems.

**Example:** Create an internal HR assistant that answers leave-policy questions from approved company documents.

### Microsoft Edge
**What it is:** Microsoft's web browser, based on the Chromium project.

**What it is used for:** Browsing websites, using web applications, managing tabs and profiles, and accessing browser security and productivity features.

**Example:** A developer tests a web application in Edge and uses developer tools to inspect HTML, CSS, and network requests.

### Microsoft Mesh
**What it is:** Microsoft's platform and experiences for immersive, spatial collaboration, including supported Teams immersive experiences and development capabilities.

**What it is used for:** Creating shared virtual environments and more immersive remote collaboration or events, where supported.

**Example:** A distributed team meets in a virtual environment for a collaborative session.

### Microsoft Teams
**What it is:** A collaboration application combining chat, meetings, calling, file collaboration, and integrations.

**What it is used for:** Team communication, online classes, meetings, project coordination, and collaboration with connected Microsoft 365 services.

**Example:** A project team creates a channel, shares files, schedules meetings, and tracks discussions in one workspace.

### Microsoft Typography
**What it is:** Microsoft's typography and font technology resources, including information about fonts and text rendering.

**What it is used for:** Understanding and using typefaces and typography technologies in documents, websites, and software.

**Example:** A designer selects a font with appropriate language coverage and readability for a user interface.

### Microsoft Viva
**What it is:** An employee experience platform integrated with Microsoft 365 and Teams, with modules that support areas such as employee communications, learning, insights, and knowledge.

**What it is used for:** Supporting employee engagement, internal communication, learning, and workplace experience.

**Example:** An organization shares internal updates and learning resources through Viva experiences.

## Power Platform and analytics

### Power Platform
**What it is:** Microsoft's low-code platform family, including Power Apps, Power Automate, Power BI, Power Pages, and related data and automation capabilities.

**What it is used for:** Building business apps, automating workflows, analyzing data, creating external-facing websites, and connecting business systems.

**Example:** A department builds a request app, routes approvals automatically, and displays request statistics in a dashboard.

### Power Apps
**What it is:** A low-code development service for building business applications.

**What it is used for:** Creating mobile-friendly or browser-based apps that connect to data sources and business workflows.

**Example:** Build an equipment checkout app for a college lab, with forms to issue and return devices.

### Power Automate
**What it is:** A workflow automation service for connecting applications and automating repetitive tasks.

**What it is used for:** Approvals, notifications, data movement, scheduled workflows, and process automation across supported services.

**Example:** When a form is submitted, automatically notify a supervisor and request approval.

### Power BI
**What it is:** Microsoft's business intelligence and data visualization platform.

**What it is used for:** Connecting to data, modeling it, creating interactive reports and dashboards, and sharing insights with permitted users.

**Example:** Create a dashboard showing monthly attendance, pass percentages, and department-level trends.

### Power Pages
**What it is:** A low-code platform for building secure, data-driven external-facing business websites.

**What it is used for:** Customer or partner portals, registration sites, service request portals, and websites connected to business data.

**Example:** Create a portal where customers submit and track service requests.

### Power Query M
See the [Power Query M](#power-query-m) entry in the cloud, data, and developer platforms section. It is the language used to express many Power Query data-transformation steps.

## Security, identity, and device management

### Microsoft Defender
**What it is:** Microsoft's family of security products and services for endpoint, identity, email, cloud, and threat protection. Specific features depend on the Defender product and license.

**What it is used for:** Detecting, investigating, and responding to security threats and helping protect devices, users, and cloud workloads.

**Example:** A security team reviews an endpoint alert and investigates suspicious activity on a managed computer.

### Microsoft Entra
**What it is:** Microsoft's identity and network access product family, including Microsoft Entra ID (formerly Azure Active Directory) and related identity capabilities.

**What it is used for:** User sign-in, single sign-on, multifactor authentication, application access, identity governance, and access policies.

**Example:** Students sign in to several approved campus applications using one institutional account and multifactor authentication.

### Microsoft Intune
**What it is:** A cloud-based endpoint management service.

**What it is used for:** Managing organization-owned or enrolled devices, deploying apps and settings, enforcing security policies, and helping protect organizational data.

**Example:** An IT administrator configures approved security settings and deploys required applications to company laptops.

### Microsoft Priva
**What it is:** Microsoft's privacy-management solution family for helping organizations identify and manage privacy risks and support privacy operations.

**What it is used for:** Privacy risk management and workflows related to personal data, subject to the available Priva products and licensing.

**Example:** A privacy team reviews alerts about potential oversharing of personal information and follows its organization's response process.

### Microsoft Purview
**What it is:** Microsoft's data governance, compliance, and information protection portfolio.

**What it is used for:** Data cataloging and governance, sensitivity labeling, data loss prevention, retention, records management, and compliance workflows, depending on the solution and license.

**Example:** An organization labels confidential files and applies policies to reduce accidental sharing.

### Microsoft Security
**What it is:** Microsoft's broader portfolio and ecosystem of security products, services, and guidance.

**What it is used for:** Protecting identities, endpoints, applications, email, cloud resources, and data through coordinated security capabilities.

**Example:** An organization combines identity controls, endpoint protection, and security monitoring as part of its defense strategy.

## Windows, infrastructure, and administration

### Windows
**What it is:** Microsoft's operating system family for personal computers and supported devices.

**What it is used for:** Running desktop applications, managing files and devices, connecting to networks, and providing a platform for work, education, and development.

**Example:** Use Windows to run Visual Studio, browse the web, write code, and manage project files.

### Windows Server
**What it is:** Microsoft's server operating system for on-premises, cloud, and hybrid infrastructure.

**What it is used for:** Hosting applications and services, managing users and computers with directory services, file and print services, virtualization, and server workloads.

**Example:** A college IT department uses Windows Server for centralized account management and shared file services.

### System Center
**What it is:** A suite of Microsoft datacenter management products, with capabilities varying by component and version.

**What it is used for:** Managing and monitoring server infrastructure, virtual machines, configuration, and IT service operations in supported environments.

**Example:** An IT team monitors server health and manages infrastructure configuration centrally.

### Sysinternals
**What it is:** A collection of advanced Windows troubleshooting, diagnostic, and administration utilities from Microsoft.

**What it is used for:** Investigating processes, startup behavior, file and registry activity, system performance, and other Windows internals.

**Example:** An administrator uses Process Explorer to inspect running processes and identify which process is using a resource.

### Microsoft Lifecycle Policy
**What it is:** Microsoft's published support lifecycle information for products, including support dates and servicing policies.

**What it is used for:** Planning upgrades, security support, maintenance, and product replacement before support ends.

**Example:** An IT department checks a product's support lifecycle to plan a migration before its support deadline.

## Other Microsoft technologies

### BizTalk Server
**What it is:** Microsoft's enterprise integration and messaging server product.

**What it is used for:** Connecting different business applications and systems, transforming messages, and orchestrating business processes in supported enterprise environments.

**Example:** Integrate an older inventory system with a newer order-processing application.

### DAX
**What it is:** Data Analysis Expressions, a formula language used in Power BI, Analysis Services, and Power Pivot.

**What it is used for:** Creating calculated columns, measures, and analytical calculations over data models.

**Example:** Define a measure that calculates total sales or year-to-date revenue in a Power BI report.

### Dynamics 365 Industry Clouds
**What it is:** Industry-focused solutions and extensions built around Microsoft business applications and cloud services.

**What it is used for:** Addressing sector-specific workflows and data needs in areas such as healthcare, financial services, manufacturing, and other industries.

**Example:** A healthcare organization uses industry-oriented capabilities alongside its broader Microsoft cloud environment.

### Microsoft Industry Clouds
**What it is:** Microsoft's broader collection of industry-specific cloud offerings, combining relevant cloud services, applications, data, and partner solutions.

**What it is used for:** Helping organizations adopt cloud capabilities tailored to the needs and terminology of their industry.

**Example:** A manufacturer combines cloud data and business applications to support production and supply-chain operations.

### Microsoft Partner Center
**What it is:** Microsoft's portal and platform for eligible partners to manage their relationship and business activities with Microsoft.

**What it is used for:** Partner account management, customer relationships, subscriptions, incentives, support, and publishing or transacting offers, depending on partner program.

**Example:** A Microsoft partner manages customer subscriptions and partner business information.

### Microsoft PlayReady
**What it is:** Microsoft's digital rights management (DRM) technology for protecting and licensing digital media.

**What it is used for:** Helping content providers control access to protected video and audio content across supported devices and services.

**Example:** A streaming service uses a supported DRM system to enforce playback permissions for licensed video.

### Microsoft Surface
**What it is:** Microsoft's family of computers and accessories, including laptops, tablets, and related devices.

**What it is used for:** Computing, productivity, education, creative work, and business use on supported hardware.

**Example:** A student uses a Surface device to take notes, attend online classes, and develop software.

### Microsoft Open Specifications
**What it is:** Microsoft's documentation and resources describing protocols, file formats, and technical specifications used by Microsoft technologies.

**What it is used for:** Helping developers and organizations understand interoperability and implement compatible software.

**Example:** A developer consults a protocol specification when building software that must exchange data with a Microsoft system.

### Microsoft Remote Assist and Guides
These are distinct Dynamics 365 mixed-reality offerings described in the Dynamics 365 section: Remote Assist supports remote expert collaboration, while Guides provides step-by-step guided instructions.
